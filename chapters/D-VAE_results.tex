\chapter{All \texorpdfstring{\acs{VAE}}{VAE} results}
\label{app:VAE-results}

This appendix contains the training and testing results for the \ac{VAE} configurations not explicitly shown in the main text. The plots reported here follow the pure reconstruction task using $\beta=1$. The results are categorised by the event selection ($1\sigma$ or $3\sigma$ around the \ac{DEP} and \ac{FEP} fits), the number of input channels (current only or both current and charge), and the applied preprocessing (scaled or normalised). For each configuration, three plots are reported: the decoder reconstruction at epochs 1, 50, and 100, the loss functions evolution and a test set reconstruction example.
